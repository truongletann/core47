# Security Policy

core47.xyz handles real user accounts and portfolio/financial data, so
security reports are taken seriously.

## Reporting a vulnerability

**Do not open a public GitHub issue for a security vulnerability.**

Instead, email **hoclamtraderxau@gmail.com** with:
- A description of the vulnerability and its impact
- Steps to reproduce (URL, request, payload — whatever's relevant)
- Any suggested fix, if you have one

You should get an acknowledgment within a few days. Please allow time for a
fix to be deployed before any public disclosure.

## Scope

In scope: anything served from `*.core47.xyz` or `to2.site` and this
repository's source code.
