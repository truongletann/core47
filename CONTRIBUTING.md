# Contributing

core47 is a personal project (core47.xyz), not built to take external code
contributions. That said:

## Reporting a bug

Open an issue with:
- What you did, what you expected, what happened instead
- URL / subdomain where it occurred
- Browser + device, if relevant to the bug

## Suggesting a feature or tool

Open an issue describing the use case. There's no guarantee it'll be built,
but ideas are welcome.

## Pull requests

Unsolicited PRs are unlikely to be merged, since this repo tracks one
person's live production app and closely follows the conventions in
[`CONVENTIONS.md`](CONVENTIONS.md). If you'd still like to submit a fix
(typo, broken link, obvious bug), keep the diff minimal and scoped to a
single change.

## Security issues

Please do **not** open a public issue for a security vulnerability. See
[`SECURITY.md`](SECURITY.md) for how to report it privately.
